# Launch material

Ready-to-use text for telling people this repository exists. **Nothing here has been
posted, submitted or sent.** These are drafts, in files, for a person to read and decide
on.

| File | What it is |
| --- | --- |
| [`show-hn.md`](show-hn.md) | A Show HN title, the URL to submit, and the author's first comment |
| [`reddit.md`](reddit.md) | One post for one subreddit, with why that subreddit and what must be checked before posting |
| [`x-bluesky-thread.md`](x-bluesky-thread.md) | A five-post thread, each post inside both platforms' limits |
| [`curated-lists.md`](curated-lists.md) | Five curated lists that take pull requests: each one's rules, the exact line to add, and the pull request title and body — plus six lists that were checked and ruled out, with the rule that ruled them out |

## The rules these drafts follow

- **Every venue's own contribution rules were read at that venue's own page**, and each
  file quotes the part that constrains what is written. Where a venue forbids the thing,
  it is named and dropped rather than worked around. One exception is marked in
  `reddit.md`: that site could not be read from the machine these drafts were written on,
  so nothing in that file claims to know what its rules say.
- **No numbers that are not measured.** Every figure in the write-up
  ([`../what-running-agents-costs.md`](../what-running-agents-costs.md)) came out of a
  ledger or a transcript, and the drafts repeat only figures from there.
- **No urgency, no scarcity, no testimonials, no promised savings.** The paid layer is
  disclosed plainly wherever it appears, and the free repository is the thing being
  shown.
- **`{{CHECKOUT_URL}}` is a placeholder.** It is not a real link yet. Replace every
  occurrence before any of this is used, or remove the line.

## Order

1. The curated-list pull requests, because they are one line each and their maintainers
   read on their own schedule.
2. The write-up, wherever it goes.
3. Show HN last, once the repository has had a few days of commits behind it.
